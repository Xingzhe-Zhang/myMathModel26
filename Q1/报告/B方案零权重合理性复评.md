# B 方案零权重的合理性复评

复评日期：2026-09-24。对象为 `Q_semantic`，不是 22 字段基线或冲突候选 `Q_rule`。复算脚本：`Code/analysis/reassess_semantic.py`；输入：`Code/outputs/q1_dimension_schemes/sample_scores_both.csv`；输出：`Code/outputs/q1_dimension_reassessment/`。

## 结论

**B 可以保留为“通用自然语言内在质量”的预设候选，但不能作为已经验证优于 22 字段基线的最终 Q。** B 将结构、复杂度和目标相关性设为零，来自构念划分和权重预算，**不是回归、人工评价或训练实验估出的零效应**。其中 DSIR 单列为目标相关性有明确的任务语义；当前结构效用高度饱和，把它们暂放诊断层有工程理由；复杂度全部置零、洁净组占总名义权重 57.27%，则缺少现有数据中的外部效度证明。后续不宜仅凭相关性、分布稳定或分数大小宣布 B 最优。

## 零权重从哪里来

配置将 25 个原子信号分入表达、知识、洁净、结构、复杂度、目标相关性六组，但 `quality_group_weights` 只列前三组。代码只向前三组的非 QuRating 概念分配 `21/22` 预算，另将 `1/22` 给三个 QuRating 核心子项。因此结构六项、复杂度两项、DSIR 三项的 `Q_semantic` 线性系数恰好为零；它们仍有独立组分数。实现没有按领域或单条样本重新分配这些零权重。

零系数不能解释为“它们对 LLM 训练没有价值”。尤其当前变换对缺失值用 A1 域中位数填补，对某些域不适用的指标置中性值 0.5，仍保留固定系数；结构指标的宽区间效用在 A1 大量取 1。检验权重前必须先检验效用标定。

## 本地数据检验：加回预算会怎样

从已冻结的全量评分表读取 A1 51,230 条、非重叠 A2 arXiv 16,104 条和非重叠 A3 GitHub 193,752 条。对原 B 分数做预设权重扰动：`B(λ,g)=(1−λ)B+λG_g`，其中 `G_g` 是程序已输出的组分数，`λ∈{0.05,0.10,0.20}`；三组同时加入时为 `0.7B+0.1G_结构+0.1G_复杂度+0.1G_目标相关性`。每个领域单独选前 20%，比较与原 B 的入选集合。A1 宏平均对七个领域等权，不让样本更多的领域主导。

| 扰动 | A1 七域前 20% 宏平均重合 | A2 新增 arXiv 重合 | A3 新增 GitHub 重合 |
|---|---:|---:|---:|
| 结构组加入 10% | 97.49% | 95.34% | 96.05% |
| 复杂度组加入 10% | 89.91% | 87.89% | 92.18% |
| 目标相关性组加入 10% | 93.63% | 76.40% | 97.43% |
| 三组各加入 10% | 85.36% | 68.89% | 90.19% |

尤其 A1 arXiv 加入 10% 目标相关性后重合率为 78.87%，A2 新增 arXiv 为 76.40%；相同扰动在新增 GitHub 中为 97.43%。这表明目标相关性对**目标与来源域**敏感，支持将 DSIR 与通用 Q 分开，但也表明一旦明确目标域，不能无条件忽略它。复杂度加入 10% 后三个数据部分的入选集合均有实质变化，因此“复杂度与 B 重复、置零无损”得不到支持。

结构组加入 10% 的影响较小，但这与现有效用的饱和有关：A1 的词数、句数、词熵、数字比例、平均词长效用满分率分别为 93.3%、96.1%、98.6%、99.1%、97.5%。**该实验检验的是当前效用编码下的排序敏感性，并未检验原始结构信号的真实训练价值。** 应先重新校准极短/极长、异常熵、数字密度等规则，或把明显异常作为领域适配的筛除条件，再比较是否进入连续 Q。

B 的洁净组名义系数总计 57.27%。把 B 精确分解为表达、知识、洁净三块后，A1 各域中洁净块对 B 方差的协方差贡献为 27.79%–45.78%，并非在每个域都贡献过半的排序方差。这避免了把名义系数误说成实测影响；但 57.27% 仍是未经效度检验的偏好预算。

所有数字为**无标签敏感性诊断**。A2/A3 是相同来源的扩展覆盖，不是独立质量真值；入选集合变化不能判定加回维度后质量更好或更坏。明细见 `zero_group_sensitivity_by_domain.csv`、`zero_group_sensitivity_macro.csv` 和 `core_variance_influence_A1.csv`。

## 与原始论文和项目对照

- [QuRating（ICML 2024）](https://proceedings.mlr.press/v235/wettig24a.html)把写作风格、所需专业知识、事实与教育价值分别用于固定 Token 预算的数据选择实验，并强调质量与多样性平衡。它支持拆开 QuRating；不能推出“所需专业知识”的普适最优权重为零。
- [Meta-rater（ACL 2025）](https://aclanthology.org/2025.acl-long.533/)把专业性、可读性、推理、洁净与既有指标联合，通过代理模型验证损失学习组合权重。其论文附录 Table 9 给专业性 4.05%、所需专业知识 3.73%，结构与 DSIR 项也均为正数；[官方数据卡示例](https://huggingface.co/datasets/opendatalab/SlimPajama-Meta-rater/blob/main/README.md)列出了这些权重。**这些权重对应作者的评分口径、语料和训练目标，不能直接移植到本题经效用变换后的信号；但它们反驳“这些维度有可靠的普适零权重证据”。**
- [DSIR（NeurIPS 2023）](https://proceedings.neurips.cc/paper_files/paper/2023/hash/6b9aa8f418bde2840d5f4ab7a02f663b-Abstract-Conference.html)以目标分布匹配定义重要性权重。因此从“通用内在质量分”移出 DSIR 有构念依据；面向特定验证目标选训练数据时，应单独使用相应的目标相关性分，而非永远置零。
- [DataComp-LM（NeurIPS 2024）](https://proceedings.neurips.cc/paper_files/paper/2024/file/19e4ea30dded58259665db375885e412-Paper-Datasets_and_Benchmarks_Track.pdf)通过固定训练条件比较数据筛选策略。论文支持最终按同 Token、同模型和同验证任务的受控训练结果选方案，而不是按无标签分布或主观语义选权重。

## 建议的下一步

1. **保留三层输出**：原始 25 维、六组概念分数、单一 Q。把当前 B 明确标为“通用自然语言候选”，继续与 A 并列，不覆盖已发布结果。
2. **先修效用再谈结构权重**：对当前满分饱和的结构指标做原文核验及领域分层阈值；对 GitHub 等非自然语言内容设置适用性规则。DSIR 保留三维目标向量，不简单取普适平均。
3. **预注册对照**：保留 A、原 B、B 加复杂度小预算、B 加重新校准的结构异常规则、面向目标域的 B+DSIR。每域相同候选池和入选比例；盲审比较质量与误伤率；若资源允许，以相同模型、Token、训练步数和多个随机种子比较验证 Loss 与下游能力。权重可用代理训练反馈学习，但必须在独立保留集上确认。

在这些效度检验完成前，不能把 B 的零权重写成“数据证明这些维度不重要”，也不能把任意加回 10% 的方案写成更优解。
