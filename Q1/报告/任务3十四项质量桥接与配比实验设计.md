> 状态：**已执行的实验设计。**十四项实验已于 2026-09-25 完成；实测数字和当前论文结论见[完整实验报告](任务3十四项质量桥接与配比完整实验报告.md)。下文保留实施前的验证门槛，第 9 节按当前完成度记录。

本设计是在已看到九项阶段结果后整理的**十四项后续协议**，不是对整个课题的盲法预注册。质量来源、数据划分和训练内选参流程保持原实验记录；**题面口径修订发生在检验结果已公开之后**：原方案把 Top-k/Regret 的配方筛选收益设为额外采纳门槛，现明确它不是任务 3 的题面要求，不再用于论文主预测模型判定。此修订只改变结果解释，不追溯改变拟合、超参数、质量门禁或验证数据。原始代码输出仍可复核，不能把修订后的评价口径称为事前预注册。

## 1. 题目目标、数据角色与可识别范围

题目要求利用 **A4–A15** 建立 17 个训练域的配比 \(p\) 与交叉熵损失的定量关系，分析各域及其组合的性能影响，并由参赛队伍论证是否、如何引入质量评分 \(Q\)。\(p_i\geq0,\ \sum_{i=1}^{17}p_i=1\)；模型须在 **A6–A11** 检验，并利用 **A12–A15** 讨论外推结论的稳健性。Loss 表有 **13 个验证域**；`nih_exporter`、`enron_emails`、`europarl`、`philpapers` 仍是 17 个输入域，只是没有同名验证 Loss 列，不能因此删除其配比。

| 附件 | 实验角色 | 使用边界 |
|---|---|---|
| A1–A3 | 任务 1/2 的 22 个官方质量字段与样本/域级评分；A1 有原文，可检验十四项信号的重建 | 三表原始记录全部用于任务 1/2；跨表同一 `(domain,id)` 去重后聚合，保留 A1 与扩展集对照。A2/A3 无原文，不能拿来做文本信号重算 |
| A4+A5 | 512 个 1M 配方及对应 13 维 Loss | 唯一的 Loss 拟合、交叉验证、超参数和模型选择来源 |
| A6+A7、A8+A9、A10+A11 | 1M、60M、1B 的真实检验配方/Loss | 一次性外部检验；后两组同时发生训练尺度变化，需单列跨尺度结果 |
| A12+A13、A14+A15 | 10B、70B 的训练配方子集与估算型 Loss | 仅作外推规则的诊断；不是独立实测大模型检验 |
| A16 | 17 域到 7 个质量域的人工参考映射 | 3 条 direct、3 条 near_direct 固定不改；11 条 `(none)` 需要有证据地推断 |
| A17+A18 | RegMix 域摘要与 `valid/` 原始文本样本 | 可估计域画像和代理质量，但不能证明样本代表训练语料，更不是已有的 17 域实测 \(Q\) |

《专家问答.txt》明确说明：A1–A3 与 A4–A15 语料库不同、来源独立，不存在题目直接给出的“17 维领域质量评分”。因此跨库 \(Q\) 是**需单独验证的先验假设**。题目主体是配比与 Loss 的定量关系及领域/组合分析；\(Loss=f(p)\) 是必需的无质量基线，\(Loss=f(p,Q)\) 可以在论证后成为更好的预测模型。固定域级 \(Q_i\) 随配比变化所产生的预测收益，不能解释为质量的独立因果效应。

A16 固定的六条关系为 `arxiv→arxiv`、`github→github`、`stackexchange→stackexchange`、`wikipedia_en→wikipedia`、`gutenberg_pg_19→book`、`pile_cc→commoncrawl`；待推断的十一域为 `dm_mathematics`、`freelaw`、`nih_exporter`、`pubmed_central`、`philpapers`、`enron_emails`、`ubuntu_irc`、`europarl`、`hackernews`、`pubmed_abstracts`、`uspto_backgrounds`。质量侧的 `c4` 仍是候选来源域，不能因六条已知映射未指向它就删掉。

## 3. 统一命名：质量来源与 Loss 模型结构分开

为消除旧版“Model-2=相似度、Model-3=直接预测”和九项新版“M2/M3=不同 Loss 表示”的重名，今后报告使用两个独立标签。

| 轴 | 代码/论文记号 | 含义 |
|---|---|---|
| 质量来源 | \(Q^{bridge}\) | A1/A18 十四项共同信号画像 → A16 六条固定 + 十一条软映射 → 任务 1/2 的七域 \(Q\) 传递 |
| 质量来源 | \(Q^{direct}\) | A18 十四项重建信号 → **复用任务 1/2 冻结评分器** → 文本级评分再按 17 域聚合；不另训五特征回归器 |
| Loss 层 | M1 | 仅 \(p\) 的基线 |
| Loss 层 | M2 | \(p\) 与汇总质量 \(Q_{mix}=p^\top Q\) 的消融对照 |
| Loss 层 | M3 | 逐域质量耦合 \(p\odot Q\) 或质量先验约束的领域贡献模型 |

先在**同一 \(Q\) 来源**下比较 M1/M2/M3，再把通过门禁的另一种 \(Q\) 来源当成稳健性对照。例如 `M3[bridge]` 与 `M3[direct]` 只比较质量来源；`M2[bridge]` 与 `M3[bridge]` 才比较 Loss 结构。旧报告中称 `M2-A18` 的是 A18 **相似度软映射**，不是 A18 直接评分；旧五特征版 `Model-3` 的结果不得混入本方案。

## 4. 第一关：冻结任务 1/2 的七域质量参照

最终主版本使用任务 1/2 的 **B20_hierarchical、frozen_original、Q_base** 评分定义、A1 冻结预处理和权重，从 A1+A2+A3 的**去重联合记录**汇总七域 \(\bar Q_g\)，不依据 A4–A15 的 Loss 重选评分权重。七域 \(Q\) 采用等文本权均值作主聚合，同时报告域内样本数、分位数、bootstrap 区间和按文本长度加权的敏感性。九项旧程序只读取 A1 域均值；十四项实验改用联合域均值，并将“A1 均值”保留为来源敏感性。A2/A3 仅增加 arxiv、github 的官方信号记录；这两个域尤其要报告扩展前后的变化。

任务 1/2 的 A22/B23/B20 是不同候选评分结构，并无独立训练收益标签能证明某一种最优。若最终论文确定其中一种为主 \(Q\)，须在观察十四项 Loss 检验结果**以前**冻结该选择；其余方案只作预先声明的评分版本敏感性。不能根据 A6–A11 哪一种增益最大再回头选择任务 1/2 的 \(Q\)。

## 5. 第二关：从 A1/A18 构造两条 17 域 \(Q\) 路线

### 5.1 画像路线 \(Q^{bridge}\)：六条老师映射锁定，十一条多对多软补全

对 A1 七域、A18 十七域的十四项共同信号，分别构造均值、标准差及稳健分位数画像。计数/长度类信号先作 `log1p`，缺失与非有限值记录原因；尺度、截断和分组权重只依据 **A1** 确定。为避免高度相关的长度统计或四个同族 ModernBERT 字段重复投票，预先把十四项分成**长度 3 项、词汇 2 项、表面/重复 4 项、FineWeb 1 项、ModernBERT 4 项**五家族，每家族先等额分配距离预算，再在家族内等分；A1 分域失配字段标记并在剔除整个字段/家族后重算敏感性。主距离以 A1 文本的字段标准差 \(s_f\) 标准化均值差和标准差差：\(d_{ig}^2=\sum_f\omega_f[(\mu_{if}-\mu_{gf})^2/s_f^2+0.25(\sigma_{if}-\sigma_{gf})^2/s_f^2]\)。分位数不另行叠入主距离，供检查重尾与抽样稳健性；这样避免把同一信息重复计权。十四项为固定主方案，九项统计画像为事先声明的消融，不因其 Loss 表现而临时择优。

对未知的 11 个 RegMix 域 \(i\)，计算与七个 A1 域 \(g\) 的稳健距离 \(d_{ig}\)，形成一行总和为 1 的权重

\[
W_{ig}=\frac{\exp(-d_{ig}/\tau)}{\sum_h\exp(-d_{ih}/\tau)},\qquad
Q^{bridge}_i=\sum_gW_{ig}\bar Q_g.
\]

\(W\) 为 \(17\times7\) 矩阵：未知域的一行可分配给多个质量域，同一质量域可覆盖多个 RegMix 域。A16 六个 direct/near_direct 域的**最终应用行固定为老师给定质量域的 one-hot 行**，无论画像首选是否相同；不改写 A16 原文件，只新增推断结果表。\(W\) 是相似度权重，**不称为校准后的真实映射概率**。预设 \(\tau=1\) 为主值，并报告 0.5/2、剔除单项/整个家族、文本重抽样、A1/联合域质量均值、硬 top-1 和第二候选替换的敏感性；尤其给 11 个未知域的首选、次选、权重熵、距离差与 \(Q\) 区间。样本不足的域不做伪精确硬归类。

六条已知 A16 关系只作**画像方法的独立核对**：暂时隐藏已知映射标签，让距离法预测，再检查首选、前三名、near_direct 与已知 \(Q\) 的误差；报告逐域结果和六域小样本区间。沿用九项阶段写明的描述性门槛：首选至少 5/6、前三名 6/6、near_direct 至少 2/3，软映射 \(Q\) 的 MAE 小于七域均值参照。画像距离/家族权重不能在同一六条标签上反复搜索后仍把这六条当“未使用检验”；如需用它们选参数，应另做留一锚点外层验证并标明探索性。十四项版另行检验后达到门槛；样本仅六条，不能视为充分泛化证明，详见[完整实验报告](任务3十四项质量桥接与配比完整实验报告.md)。

### 5.2 独立路线 \(Q^{direct}\)：十四项重建信号复用任务 1/2 评分

对 A18 每条文本，把通过审计的十四项放回任务 1/2 评分器的相应原始字段位置；未能重建的八个官方字段保持缺失，由**冻结的 A1 预处理器**按原缺失规则处理，不把它们误写成已复现。公开模型信号可对照“原始代理值”与“仅用 A1 训练折拟合的简单单调/仿射校准值”，因为总体相关通过并不保证均值相等；校准若增加复杂度，须在 LODO 内折选择，最终参数只用 A1 拟合，不能看 A18 或 Loss 标签。沿用同一效用方向、归一化和权重后产生文本级代理 \(\widehat Q_t\)，再以 A18 每域的文本样本聚合为 \(Q^{direct}_i\)，给出均值、中位数、分位数与分域 bootstrap 区间。RegMix 17 域不应为填补缺失字段而重拟合任务 1/2 的参数；它们在 A1 预处理器中属于未见域时，应使用预定义的全局后备规则。此路线上没有新的“文本特征→Q”回归模型。

必须先在 A1 做 **Leave-One-Domain-Out**：每折仅用其余六域拟合预处理与任务 1/2 权重，使用这个**同一折内评分器**分别给留出域的官方完整 22 字段和重建十四项打分，以前者作为折内参照，避免完整 A1 拟合参数含留出域而泄漏。同时输出“十四项官方原值、其余八项缺失”输入同一评分器的中间对照，以分开诊断**信号重建误差**和**八项缺失造成的信息损失**。至少报告七域逐域样本级 RMSE/MAE、域均值偏差、域级排序、与常数均值基线比较，以及六条 A16 锚点的 \(Q\) 一致性。沿用既有九项直接评分门槛：LODO 宏 RMSE 优于常数基线、域均值 MAE 不高于基线的 80%、最大域均值绝对误差不超过 0.08；再检查抽样与缺失规则的稳定性。九项版**未通过**（最大域均值误差约 0.112），十四项版已通过上述门槛，但不代表 A18 代理质量等于实际训练语料质量；数字见[完整实验报告](任务3十四项质量桥接与配比完整实验报告.md)。

两个路线的 \(Q\) 都只能视为 A18 `valid/` 样本的代理。用 A17/A18 覆盖、路径、样本数和长度分布审计其适用范围；附件没有固定配比、只改变文本质量的训练实验，无法确认它们等于实际 RegMix 训练语料质量。质量来源和不确定性必须传递到最终解释。

## 6. 第三关：单纯形上的统一 Loss 对照

每张配方表按 `index` 与 Loss 表一对一连接；检查 17 列有限、非负与原始行和，记录舍入误差后只在建模副本中按行归一化。不要删除 4 个无同名 Loss 的训练域，也不要把 13 个验证 Loss 拼作相同含义的训练域质量。比较中的所有 \(Q_i\) 均在读 A4–A15 Loss 前冻结，并在 17 域内以固定变换居中/缩放。

| 层次 | 固定实现 | 必要对照和解释 |
|---|---|---|
| M1：\(Loss=f(p)\) | 现有 17 域 RBF 核岭回归、13 维 Loss 输出；另用无截距的二次 Scheffé 混合模型解释领域与组合 | 它是题目主体，也是 M2/M3 的共同基线。Scheffé 在单纯形上不额外同时放全部平方项与截距 |
| M2：\(Loss=f(p,Q)\) | 同族 RBF 模型输入 \([p,\alpha Q_{mix}]\)，\(Q_{mix}=\sum_i p_iQ_i\)，\(\alpha=0\) 纳入训练内网格 | 只作汇总质量表示的消融；在普通线性混合模型中与 \(p\) **完全别名**，不增加可独立识别的效应 |
| M3：\(Loss=f(p,Q,pQ)\) | 同族 RBF 输入 \([p,\alpha(p\odot Q)]\)；优先报告同族二次 Scheffé 的质量先验收缩：\(\beta_i\) 向 \(a+bQ_i\) 靠拢，惩罚强度由 A4+A5 选取，可信度低的域惩罚较弱 | \(Q_{mix}=\sum_i p_iQ_i\)，故 M3 特征中不再重复追加 \(Q_{mix}\) 列；\(\alpha=0\)/零先验惩罚恢复同族无质量模型 |

质量先验的一种可审核写法是 \(\rho\sum_i r_i(\beta_i-a-bQ_i)^2\)，其中可靠度 \(r_i\) 由 A16 来源、文本样本量和画像稳定性确定，六条给定关系高于低置信度推断关系；\(\rho=0\) 是完全相同的无质量二次模型。必须同时比较 `M3[bridge]` 对无质量**二次**基线、RBF `M3[bridge]` 对无质量 **RBF** 基线，不能拿不同模型家族间的差异冒充 \(Q\) 的增益。

若 \(Q_i\) 对每个域固定，则 \(Q_{mix}=p^\top Q\)、\(p_iQ_i=Q_i p_i\) 都是 \(p\) 的确定函数；例如线性式 \(\sum_i\beta_i p_i+\gamma\sum_i p_iQ_i=\sum_i(\beta_i+\gamma Q_i)p_i\)。因此质量块在 RBF 中改变的是距离几何，在 Scheffé 中改变的是系数先验，**不是额外观测到的独立质量变化**。关于“质量的边际因果效果”不能从这些表识别。

执行时使用以下**固定分组矩阵**，同一行的不同质量来源须共用完全相同的数据划分和 Loss 选择规则：

| 组别 | 十四项主对照 | 启动条件 | 应与谁比较 |
|---|---|---|---|
| G0 | M1-RBF：仅 \(p\) | 无质量门禁 | 所有 RBF 质量组的共同基线 |
| G0s | M1-Scheffé：仅 \(p\) 及 \(p_ip_j\) | 无质量门禁 | 质量系数先验组的**同族**基线 |
| G1 / G2 | `M2[bridge]` 汇总质量 / `M3[bridge]` 逐域耦合 | 十四项 A16 锚点校验通过 | G0；G2 还与 G1 比较表示方式 |
| G3 | `M3prior[bridge]` 质量系数收缩 | 同上 | G0s，不拿跨家族差异宣称质量收益 |
| G4 / G5 | `M2[direct]` / `M3[direct]` | 十四项直接评分 LODO 通过 | G0；再与相同结构的 bridge 组比较质量来源 |
| G6 | `M3prior[direct]` | 同上 | G0s 与 G3 |
| S1 / S2 / S3 | 九项画像、硬 top-1/第二候选、A1/联合七域 \(Q\) 等敏感性 | 仅对应主质量路线已过门禁后解释稳定性 | 各自固定结构和参数的十四项主组；不把它们当新模型搜索池 |

若 `Q^{bridge}` 或 `Q^{direct}` 未过自身门禁，相应 G 组标记“**未获准进入 Loss 比较**”，不是填零、用九项结果替换或在 A6–A11 上补救调参。M1/G0 始终可独立回答题目主体。

## 7. 统一训练、检验、外推与题面模型判定

1. **训练选择：**A4+A5 的 512 个配方作固定分组五折交叉验证，近邻配方同组；三层模型、两条获准的 \(Q\) 路线共用同一分折、13 维原始 Loss、RBF 核宽度与正则化网格。质量块权重、先验强度、主用模型只由训练内 CV 确定。可另列“各输出按 A5 训练标准差标准化”的敏感性，但不能只改质量模型的目标尺度。
2. **外部检验：**在 A6/A7 的 1M 同尺度、A8/A9 的 60M、A10/A11 的 1B 分别报告 13 维总体与逐验证域的 RMSE、MAE、\(R^2\)；宏 Loss Spearman 可辅助判断配比相对性能关系。给出相对无质量基线的同配方成对 bootstrap 区间，分别列出各尺度结果，不能合并不同尺度的原始 RMSE。
3. **跨尺度解释：**模型只在 1M 的 Loss 标度训练，直接预测 60M/1B 原始 Loss 可能出现负 \(R^2\)。负 \(R^2\) 说明数值标定差；即使相对基线 RMSE 降低，也不能声称跨尺度绝对 Loss 已预测准确，更不能用检验 Loss 标签回标定后报告原协议效果。
4. **外推稳健性：**A12/A14 的 63 个配方均来自 A4 子集，A13/A15 为幂律估算 Loss。比较估算型 Loss 的预测误差、相关性及质量来源/映射情景敏感性，只讨论与该外推规则的一致性，不称真实 10B/70B 泛化验证；外推表不参与选模。
5. **题面模型判定：**先确认 A1 信号及 A16 映射或 A1 LODO 的 \(Q\) 门禁，再由 A4+A5 CV 选择质量与无质量候选，使用 A6–A11 检验配比—Loss 预测。十四项实验中 M3-direct 的 13 输出 RMSE 在三个真实检验集均优于其他候选，因此是当前的**主预测模型**；M1-RBF 是无质量基线，二次 Scheffé 和可行配比替换用于领域/组合解释。A12–A15 上 M3-direct 优势消失，须限制外推结论。此结论是结果公布后的论文判断，不伪称事前以检验集制定的选模规则。

## 8. 题目要求的领域及组合影响不能被质量对照替代

对无质量的解释模型，在已观测配比支持范围内做可行的占比转移：从域 \(a\) 向域 \(b\) 转移固定 \(\delta\)（例如 5 个百分点且不越过边界），计算 13 个验证域与宏 Loss 的预测变化，并对不同起点重复。二次 Scheffé 的 \(p_ip_j\) 项、成对中点非加性以及 bootstrap 区间用于分析组合效应；报告正负方向、适用配比区间、稀疏区域的低可信度，不把某个 \(\beta_i\) 或 \(Q_i\) 简化为“该域普遍有益”。现有替换效应和组合证据见[配比与验证 Loss 报告](任务3配比与验证Loss.md)，**它们是无质量模型的解释，不自动等于 M3-direct 的效应**。
