# 任务 3：配比与质量建模结果

实验日期：2026-09-25。程序、配置和逐项结果分别见 [运行入口](../../Code/scripts/run_quality_mixture_14_stage.py)、[冻结配置](../../Code/configs/q1_quality_mixture_14_stage.json) 和 [结果目录](../../Code/outputs/q1_quality_mixture_14_stage/)。配比基线、领域效应与实验协议分别见[配比基线报告](任务3_配比基线.md)和[实验方案](任务3_实验方案.md)。

**按题面修订的结论。**十四项共同信号的画像桥接和直接评分均通过预设质量门槛。A4+A5 五折交叉验证选中逐域直接质量耦合模型 M3-direct；它在 A6–A11 三个实际检验集的 **13 输出 RMSE 均为本轮候选模型中最低**，因此作为本题的**主预测模型**。M1-RBF 是不引入质量的基线；二次 Scheffé 模型辅助解释领域及组合效应。A12–A15 的估算型外推表上，M3-direct 的误差和宏 Loss 排序比基线差，说明外推结论不稳健。固定域级质量先验不能识别独立的质量因果效应。

本段是看到检验结果后的**论文评价口径修订**，没有重新拟合模型或改动数据划分。原实验设计曾额外要求“配方筛选指标也改善”才能采纳质量模型；题目并未要求找最优配方，因此该门槛不用于判定问题一任务 3 的主预测模型。下文以 Loss 预测误差、领域/组合分析和外推诊断回答题面。

## 数据角色与质量口径

题目要求建立 17 个训练域配比与 13 个验证域交叉熵 Loss 的关系，分析领域及组合影响，并论证质量评分是否有用。A4+A5 的 512 个 1M 配方仅用于训练、五折交叉验证及选模；A6+A7 的 256 个 1M、A8+A9 的 256 个 60M、A10+A11 的 64 个 1B 配方作实际 Loss 检验。A12–A15 每组 63 个配方都是 A4 子集，Loss 来自幂律估算，仅作外推诊断。配方按 index 配对，17 个输入域保留，建模副本按行归一化。

主质量分在读任何 Loss 前固定为 **B20_hierarchical、frozen_original、Q_base、A1+A2+A3 去重联合七域均值**。依据[任务 1/2 完整对照](任务1-2_质量评分对照.md)，A1 中三项 DSIR 原值两两 Spearman 为 0.9968–0.9990，合并可控制冗余；QuRating 四项语义不同，先作家族内加权、再给家族一个外层预算，避免 B23 平铺后家族权重达约 20.89%。原尺度 B20 与 A22 的 A1 前 20% 等域平均重合 96.14%，而 DSIR 百分位改变排序明显。因此以原尺度 B20 作结构较克制的主先验，A22、B23、DSIR 百分位和仅 A1 参考源作敏感性。没有独立训练价值标签，不能把 B20 称为已验证的最优质量分；冲突惩罚候选分 Q_rule 不进入主实验。

A1 七域各取 64 条，A18 十七域共取 1,040 条。通过 A1 总体复现审计的是 9 项 RedPajama 统计信号及 5 项公开模型信号；两项统计与 fluency_en 代理未通过，均排除。公开模型仍有分域失配：ModernBERT 的 cleanliness/readability 在 book、reasoning 在 arxiv/book/github 的审计未通过。画像距离按长度、词汇、表面/重复、FineWeb、ModernBERT 五个家族各占 20%，家族内均分；长度信号取 log1p，以 A1 尺度标准化。字段、家族权重、校准参数和输入指纹见 [信号记录](../../Code/outputs/q1_quality_mixture_14_stage/signal_manifest.json)。

## 两条跨库质量路线及门禁

## 同一分折的配比—Loss 对照

512 个训练配方形成 512 个近重复组，共用五折 103/103/102/102/102，以 13 个原始 Loss 的均方误差选参。M1-RBF 只输入配比 p；M2 在 RBF 输入中追加配方质量汇总 α(p·Q)；M3 追加 17 维逐域项 α(p⊙Q)；M3prior 在二次 Scheffé 模型中把线性领域系数向 a+bQ 收缩。α=0 和零先验强度都在网格中；M3prior 与同族 M1-Scheffé 比较。所有模型的分折相同，外部 Loss 不参加选择。

| 模型 | A4+A5 CV RMSE |
|---|---:|
| M1-RBF | 0.50882 |
| M1-Scheffé | 0.55521 |
| M2-bridge / M2-direct | 0.50866 / 0.50696 |
| M3-bridge / **M3-direct** | 0.50802 / **0.49811** |
| M3prior-bridge / M3prior-direct | 0.55517 / 0.55517 |

M3-direct 由 CV 选出的参数为 α=1.5、γ=1、λ=0.0001；M1-RBF 为 γ=0.25、λ=0.0001。二次先验较同族基线的 CV 改善约 0.00004，不代表超过 RBF。新运行 M1 在 1M 的 RMSE 0.478791 与[原报告](任务3_配比基线.md)一致。

## 敏感性、外推与主体领域效应

固定 M3 主实验超参数，在 A4+A5 重新拟合桥接十一域硬首选/第二候选、A22/B23 替换、DSIR 百分位、仅 A1 参考源、桥接温度 0.5/2，以及直接路线公开模型不校准情景；六条 A16 锚点在硬映射情景仍锁定。没有用外部 Loss 追选情景。结果见 [质量来源敏感性](../../Code/outputs/q1_quality_mixture_14_stage/quality_source_loss_sensitivity.csv)。桥接硬首选与硬第二候选在 1M 的 RMSE 分别为 0.47972、0.47756，没有复制 M3-direct 的明显预测增益。未校准 M3-direct 在 1M/60M/1B 的 RMSE 约 0.45426/1.56735/2.84931，接近校准主值；A1 留一域中未校准信号的宏 RMSE 为 0.03962，反而低于校准版 0.04902，故**不能宣称仿射校准提高了质量估计的跨域准确性**。桥接的删单项、删家族、温度与抽样敏感性见 [映射敏感性](../../Code/outputs/q1_quality_mixture_14_stage/mapping_and_sample_sensitivity.csv)。

10B/70B 估算表均为 A4 中 63 个已见配方子集。M1 的 RMSE 为 3.61822/4.00385、宏排序 Spearman 为 -0.59365/-0.66086；M3-direct 为 3.62539/4.01184、-0.64276/-0.71496，均未改善。它们只是[外推规则诊断](../../Code/outputs/q1_quality_mixture_14_stage/extrapolation_diagnostics.csv)，不是独立的大模型训练验证。

题目要求的领域和组合影响由**无质量的解释模型**单独回答：在观测配方附近做可行的 5% 有向替换，并用二次 Scheffé 模型考察组合。50,000 个训练配方对的中点非加性量均值 -0.04461，范围 [-0.38043, 0.14070]，正负均存在；这是该模型中的非线性混合效应，不是质量协同的因果证据。各方向的支持配方数、13 域响应和区间见 [替换效应](../../Code/outputs/q1_task3/replacement_effects.csv) 与 [组合汇总](../../Code/outputs/q1_task3/combination_effect_summary.csv)。**这些数值来自 M1/二次模型，不能写成 M3-direct 的领域贡献或组合效应。**M3-direct 负责更准确的 Loss 定量预测；两类模型各回答题目的一部分。

论文正文宜以 **M3-direct 的配比—Loss 定量关系和 A6–A11 检验结果**作为预测主线，以 **M1-RBF 为无质量对照、二次 Scheffé 与可行配比替换为领域及组合解释**。同时明确：现有领域效应解释并非来自 M3-direct；M3-direct 在 A12–A15 估算外推表上未保持优势，且 A18 `valid/` 的域质量只是跨库代理。只有获得更接近实际训练语料的独立质量证据，或同一配比下改变文本质量的受控训练反馈，才可能提出更强的质量效应主张。
