# 问题一任务 3：A1 文本质量信号复现审计（Loss 暂停）

本轮只核验文本质量信号，不训练 A4–A15 的配比→Loss 模型。A1 的七个质量域各按固定哈希抽取 64 条，共 448 条，以同一份 `content` 重算 11 个 RedPajama 类统计字段，并与题目官方数值逐条比较。判定门槛预先固定为 Pearson 相关系数至少 0.95，且 MAE 不超过官方值四分位距的 10%。百分比字段以下均用题目原始的 0–100 单位，计数和熵保留原单位。

| 指标 | 官方均值 | 重算均值 | MAE | Pearson r | 通过 |
|---|---:|---:|---:|---:|:---:|
| `rps_doc_word_count` | 13227.504 | 13227.504 | 0 | 1.0000 | 是 |
| `rps_doc_num_sentences` | 904.571 | 904.571 | 0 | 1.0000 | 是 |
| `rps_doc_unigram_entropy` | 5.032 | 5.032 | 0 | 1.0000 | 是 |
| `rps_doc_frac_unique_words` | 45.177 | 45.432 | 0.400 | 0.9970 | 是 |
| `rps_doc_frac_no_alph_words` | 27.575 | 27.575 | ≈0 | 1.0000 | 是 |
| `rps_doc_frac_chars_top_2gram` | 2.811 | 2.874 | 0.063 | 0.9988 | 是 |
| `rps_doc_frac_chars_top_3gram` | 2.230 | 2.340 | 0.110 | 0.9979 | 是 |
| `rps_lines_uppercase_letter_fraction` | 23.046 | 4.421 | 18.625 | −0.0520 | **否** |
| `rps_lines_ending_with_terminal_punctution_mark` | 54.340 | 35.261 | 19.256 | 0.8512 | **否** |
| `rps_lines_numerical_chars_fraction` | 2.768 | 2.769 | 0.001 | 1.0000 | 是 |
| `rps_doc_mean_word_length` | 5.940 | 5.940 | 0 | 1.0000 | 是 |

**结论是 9 项通过，2 项不通过。** 五项可逐条精确复现：词数、句数、单词熵、`frac_no_alph_words`、平均词长；数字比例几乎逐条一致（448 条中 99.1% 的绝对误差 ≤10⁻⁶）。独特词比例与两个 n-gram 比例虽然有少量偏差，但满足预设的相关和归一化误差门槛。两个行级字段的误差明显，不能因为名字和 [RedPajama 原项目](https://github.com/togethercomputer/RedPajama-Data) 相同，就宣称官方标量已复现。尤其 `frac_no_alph_words` 在本题 A1 中实际对应“非字母**字符**比例”；这是逐条比对得到的数据事实，与原项目字段名的通常解释不同。

模型类的六项——`fineweb_edu`、`fluency_en` 和四个 `modernbert_*`——需要运行固定版本的公开权重后，才能填入同格式的完整 17 项误差表。五项有对应的 [FineWeb-Edu 分类器](https://huggingface.co/HuggingFaceFW/fineweb-edu-classifier) 和 [Meta-rater PRRC 权重](https://github.com/opendatalab/Meta-rater)；`fluency_en` 的万卷原始权重暂未找到公开下载地址，因此脚本将 [CoLA 语法可接受度模型](https://huggingface.co/textattack/roberta-base-CoLA) 作为候选代理，必须经 A1 对照，不能把它称为官方同模型复现。
