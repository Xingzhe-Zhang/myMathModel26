# 问题一：22 字段基线与语义分组方案的设计、实证和选择

计算日期：2026-09-24。数据：A1 51,230 条、A2 17,523 条、A3 203,752 条，去重后 261,086 条。两方案在同一份 A1 拟合的效用尺度上评分，A2/A3 只用冻结规则。运行程序为 `Code/scripts/compare_dimensions.py`，配置和完整结果分别为 `Code/configs/q1_dimension_schemes.json`、`Code/outputs/q1_dimension_schemes/`。专家答复允许有依据地升维和降维，并说明综合评价的目标是在已有冲突下形成可信、稳健、可解释的评价，而非降低冲突概率。

## 两种方案怎样改变维度

**方案 A：22 字段基线。** `Q22_equal` 等于原任务 1、2 的 `Q_base`，每字段占 1/22；`qurater` 四项各占 1/88。全量 261,086 条与既有 `Q_base` 按 `uid` 配对后，最大数值差为 4.44×10⁻¹⁶。

**方案 B：25 原子信号＋语义概念。** 先把 QuRating 拆成写作风格、所需专业知识、事实知识、教育价值；二分类和六等级 logits 仍各转成一个正向分数，不把互斥类别伪装成多个独立维度。25 项按发布方语义完整分配：

| 层次 | 原子信号 | 进入 B 的单一 Q？ | 原因 |
|---|---|---|---|
| 表达 | 流畅、可读、QuRating 写作风格 | 是 | 直接描述文本表达 |
| 知识与学习 | FineWeb 教育、推理、QuRating 事实知识与教育价值 | 是 | 更接近知识学习内容 |
| 洁净 | ModernBERT 洁净、无广告、非字母比例、2/3-gram 重复、异常大写、句末标点 | 是 | 与噪声、广告、格式和重复相关；2/3-gram 共享一个“重复”概念预算 |
| 结构 | 词数、句数、词熵、独特词比例、数字比例、平均词长 | 单列诊断 | 受长度与领域影响；现有区间效用高度饱和 |
| 复杂度 | ModernBERT 专业性、QuRating 所需专业知识 | 单列诊断 | 高专业门槛不必然代表普适质量高 |
| 目标相关性 | DSIR books/wiki/math | 保留三维向量 | 针对不同目标分布，不是普适质量标签 |

B 的十个非 QuRating 核心概念等权；QuRating 在 B 中仍占总质量分的 **1/22**，由进入核心的三个子项均分。这样拆分不自动把该模型家族放大。三个核心组表中的 0.2、0.2、0.6 来自各自拥有 2、2、6 个非 QuRating 概念；可在 `dimension_weights.csv` 查看 25 个原子信号在两方案中的实际系数。该等权是可复现的候选偏好，并非已学得的最优值。B 更偏向自然语言文本质量；当前指标不足以测量代码可执行性或正确性，不能把 GitHub 的 B 分数较低直接解释为代码质量差。

## 改维度有哪些客观依据

A1 的三个 DSIR 指标两两 Spearman 相关为 0.997～0.999，在新增的 A2 arxiv 中仍为 0.993～1.000，在新增的 A3 github 中约为 1.000。因此将其从普适单分中移出、保留目标相关性向量有较强的数据依据。[DSIR 原论文](https://proceedings.neurips.cc/paper_files/paper/2023/hash/6b9aa8f418bde2840d5f4ab7a02f663b-Abstract-Conference.html)也明确这些是面向目标分布的重要性信号。

其他“看起来相近”的信号不能按总体相关直接合并：FineWeb 教育分与 QuRating 教育分在 A1 的相关为 0.596，但在新增 arxiv/github 中为 0.329/0.314；可读性与流畅度从 A1 的 0.577 降至 0.207/0.211。2-gram/3-gram 重复相关分别为 0.484、0.364、0.565，足以作为一个语义概念报告，却不是近似相同的列。QuRating 写作风格与所需专业知识在 A1 的相关仅 0.127，发布方和[QuRating 论文](https://proceedings.mlr.press/v235/wettig24a.html)也将四项作为不同性质的评价，因此拆分展示有充分理由。

A1 中词数、句数、词熵、数字比例、平均词长的效用满分率分别为 93.3%、96.1%、98.6%、99.1%、97.5%。这主要反映当前宽区间内统一赋 1 的变换，并不证明这些原始信号没有价值。先把它们放入结构诊断、保留原始值和异常率，优于在未经校准的情况下让这些近常数效用继续抬高 Q。RedPajama 也把自然语言统计量作为可配置的[质量信号和筛选规则](https://github.com/togethercomputer/RedPajama-Data/blob/main/README.md)，而非宣称每项与普适训练效用等价。

冻结规则在非重叠扩展集上的平均分变化：A2 arxiv 相对 A1，A 为 −0.00172，B 为 −0.00080；A3 github 相对 A1，A 为 −0.00039，B 为 −0.00032。两者的分布都较稳定。B 的 arxiv KS 距离 0.021，小于 A 的 0.043；github 为 0.011 与 0.014。KS 距离只衡量分布差异，**不能证明 B 更接近质量真值**。A2/A3 也只有 arxiv/github 扩展，且原数据与 A1 有重叠，因此比较使用了非重叠部分。

## 选择规则和当前判定

**当前判定：未能选出更优的质量模型。** A1–A3 没有逐样本独立质量真值，也没有“按两个方案筛选后、在相同算力下训练模型”的反馈。相关、稳定性、内部一致性、分数方差或排名变化均不足以解决效度问题。[Meta-rater](https://aclanthology.org/2025.acl-long.533/)通过代理模型训练反馈学习组合权重；[DataComp-LM](https://proceedings.nips.cc/paper_files/paper/2024/hash/19e4ea30dded58259665db375885e412-Abstract-Datasets_and_Benchmarks_Track.html)在固定模型和计算条件下评价数据整理方法，均支持用外部结果选方案。

已生成 7 域各随机 60 篇、共 420 篇且不含模型分数的 `blind_review_template.csv`。长文本完整内容另存于 `blind_review_fulltext.jsonl`，标注前须按 `uid` 阅读完整原文。先由两名评阅者独立标记总体质量（0～1）和明确缺陷（0/1），记录评阅一致性，分歧裁决后形成 `uid,quality,defect` 终评表。两模型在每域各自选择前 20%，比较入选文本的人评质量均值和缺陷率，7 域等权宏平均；按域配对重抽样给差值 95% 区间。默认需至少 200 条且每域至少 20 条有效标注。只有 B 的人评质量增益区间下限大于 0、缺陷率增幅区间上限低于预设 2 个百分点、各域无超过 0.05 的质量下降，程序才报告“B 在此标注集获得支持”。阈值是预注册的工程取舍，不是论文通用定理。若证据不足，继续将 A 作为可复现主基线，同时并列报告 B。

若算力允许，还应在**相同原始候选池、每域配额、Token 预算、模型规模、训练步数、随机种子与验证集**下仅改变按 A/B 选择的数据，重复训练小代理模型，比较验证 Loss 和下游任务；这是决定训练效用的更直接证据。训练效用与人工质量可以分别得出不同结论，不必压成同一标量。完整运行与标注格式见 `Code/docs/dimension_schemes.md`。
