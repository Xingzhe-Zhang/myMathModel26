# 问题一总体方案

> **22 维质量指标直接评价；用样本内部的高低分歧定义冲突，用相关分析、因子分析和原文核验解释冲突；通过具有单调性保证的有限补偿模型得到最终质量分；最后用满足单纯形约束的回归模型研究 17 域配比与 13 项验证 Loss 的关系。**

这套方案不需要把 22 维人为分成四组，能够逐项对应题目要求，也能衔接问题二。

先说明：下面给出的是完整、可实施的建模方案。最终哪些领域质量最高、哪些配方最好、模型误差多大，必须由实际计算得到。本轮没有执行全量评分和模型拟合，因此不会编造这些结果。

还需要修正前面讨论中的三处问题：

- **负相关不是样本冲突的必要条件。** 两个总体正相关的指标，也可能在某篇文本上一个很高、另一个很低。
- **冲突惩罚不能随意相减。** 未加约束的 \(Q=Q_0-\lambda K\)，或让混合权重随 \(K\) 自动变化，都可能出现“一个正向指标提高，最终质量反而下降”。
- **之前的高低冲突乘积公式有误。** 两个因子同时为负时，乘积也为正。必须分别取正部，才能正确识别“一高一低”。

以下方案统一解决这些问题。

---

**一、明确问题一的三个任务和最终输出**

| 任务 | 核心问题 | 最终输出 |
|---|---|---|
| 数据质量评价 | 每条文本、每个来源域的质量如何？ | 样本质量 \(Q_i\)、域级质量 \(Q_g\)、A1 与 A2/A3 对照 |
| 质量冲突消解 | 哪些文本存在质量分歧？为什么？如何合理评分？ | 冲突标签、强度、类型、成因证据，以及考虑冲突后的 \(Q_i\) |
| 领域配比建模 | 改变 17 个领域的占比，会怎样影响验证 Loss？ | 13 个 Loss 预测模型、领域替换效应、组合效应、检验与外推结果 |

统一使用以下符号：

\[
i=\text{文本编号},\qquad j=1,\ldots,22=\text{质量指标编号},
\]

\[
g=\text{质量信号来源域},\qquad
a=1,\ldots,17=\text{训练配方域},
\]

\[
k=1,\ldots,13=\text{验证 Loss 域}.
\]

注意，**7 个质量来源域、17 个训练域、13 个验证域是三套不同对象**，不能混用。

合计为：

272\,505.

这是文件记录总数，不一定是独立文本数量。

**2. 先正确解释指标，再进行归一化**

列表型指标不能统一取平均。根据数据发布方说明，二分类字段、等级分类字段和多维评分字段的含义不同。[原始数据字段说明](https://huggingface.co/datasets/opendatalab/SlimPajama-Meta-rater/blob/main/README.md)

对于二分类 logits：

\[
\pi_h=\frac{\exp(\ell_h-\ell_{\max})}
{\sum_t\exp(\ell_t-\ell_{\max})}.
\]

分别取：

\[
z_{i,\mathrm{fluency}}=\pi_1,
\]

\[
z_{i,\mathrm{no\ ad}}=\pi_1.
\]

其中 `ad_en` 的类别顺序是“有广告、无广告”，所以第二类转换后的分数已经是越高越好，不能再反向。

对四个 `modernbert_*` 字段，采用标准化等级期望：

\[
z_{ij}=\sum_{h=0}^{5}\frac{h}{5}\pi_{ijh}.
\]

同时以“最大 logit 对应等级除以 5”做敏感性分析。等级期望是本方案的连续化选择，不意味着分类概率已经完成统计校准。

对 `fineweb_edu`，提取单元素列表中的数值。

对 `qurater`，其四项是不同含义的评分，先分别转换成可比效用，再合成为一个字段：

\[
z_{i,\mathrm{qurater}}
=\sum_{h=1}^{4}a_hT_h(x_{ih}),
\qquad
a_h\ge0,\quad\sum_ha_h=1.
\]

可以从四项等权开始，将不同权重作为敏感性分析。

建议采用以下处理口径。表中“适宜性”不是把所有文本强行变成同一种风格，而是判断是否超出合理范围。

| 字段 | 建议处理 | 主要注意事项 |
|---|---|---|
| `fineweb_edu` | 教育价值正向归一化 | 提取单元素 |
| `fluency_en` | 流畅类别分数 | 按 logits 转换 |
| `modernbert_cleanliness` | 等级期望 | 洁净程度 |
| `modernbert_readability` | 等级期望 | 可读性 |
| `modernbert_reasoning` | 等级期望 | 推理内容 |
| `modernbert_professionalism` | 等级期望 | 专业性与普适质量不完全等价 |
| `qurater` | 四子项归一化后合成 | 不能把四项当互斥类别 |
| `ad_en` | 无广告类别分数 | 避免反向两次 |
| `dsir_books` | 正向单调转换 | 书籍目标域相关性 |
| `dsir_wiki` | 正向单调转换 | 百科目标域相关性 |
| `dsir_math` | 正向单调转换 | 数学目标域相关性 |
| `rps_doc_word_count` | 对数变换、长度适宜性 | 长度不是越大越好 |
| `rps_doc_num_sentences` | 对数变换、结构适宜性 | 与词数相关 |
| `rps_doc_unigram_entropy` | 合理区间或饱和效用 | 高熵也可能来自乱码 |
| `rps_doc_frac_unique_words` | 词汇多样性效用 | 受文本长度影响 |
| `rps_doc_frac_no_alph_words` | 非字母异常程度反向化 | 公式、代码应有合理容许范围 |
| `rps_doc_frac_chars_top_2gram` | 重复程度反向化 | 注意领域差异 |
| `rps_doc_frac_chars_top_3gram` | 同上 | 与上一项有冗余 |
| `rps_lines_uppercase_letter_fraction` | 异常大写程度反向化 | 缩写不等于噪声 |
| `rps_lines_ending_with_terminal_punctution_mark` | 文本结构适宜性 | 代码不能按散文规则评价 |
| `rps_lines_numerical_chars_fraction` | 数字比例适宜性 | 数学文本数字多很正常 |
| `rps_doc_mean_word_length` | 词长适宜性 | 极端值可能来自长字符串 |

这里的目标是将每个原始信号转换为：

\[
z_{ij}\in[0,1],
\]

且“越高越好”。

对于专业性、DSIR 等指标，“好”取决于训练目标，应在论文中明确采用“通用预训练兼顾知识、推理和专业内容”的评价口径，并检查降低这些指标权重后结论是否改变。

**4. 缺失、极端值与适中型指标的处理**

先检查字段类型、列表长度、缺失、无穷值、比例单位及重复记录。

普通连续正向指标可使用固定参考分位点：

\[
T_j(x)=
\operatorname{clip}
\left(
\frac{x-a_j}{b_j-a_j},0,1
\right).
\]

负向指标使用：

\[
T_j^{-}(x)=1-T_j(x).
\]

适中型指标可采用区间效用：

\[
T_j(x)
=
\exp\left[
-\left(
\frac{\operatorname{dist}(x,[l_j,u_j])}{s_j}
\right)^2
\right].
\]

合理区间内取高分，超出区间后逐渐降低。区间依据应来自原始文本核查和文献定义；经验分位数只能提供初值，不能证明“多数文本所在区间就是高质量区间”。

针对代码、公式等领域差异，可以设置有依据的适用规则，但不能将每个域都机械地映射到相同均值，否则会人为抹平域间差异。

缺失值以固定参考样本的域内中位数插补，并输出每条记录的有效指标覆盖率。高缺失文本应附带“不确定性较大”的说明，不自动判定为低质量。常数指标没有区分能力，应报告并防止除零。

**5. 固定评分尺度，保证 A1 与扩展集可比较**

建议先在 A1 上确定：

\[
\mathcal P=
\{\text{转换规则、参考尺度、权重、冲突阈值}\},
\]

随后冻结 \(\mathcal P\)，应用于 A1、A2、A3 全部记录。

由于 A1 各域样本数量不均衡，参考统计量可采用域平衡权重：

\[
a_i=\frac{1}{7n_{g(i)}}.
\]

这样每个来源域对参考尺度的总贡献相同。小样本域仍有较大估计不确定性，应在重抽样中体现。

不得分别在 A1、A2、A3 中归一化、估权，然后直接比较分数。

**6. 不分组，建立 22 维基础质量分**

定义：

\[
\boxed{
Q_i^{(0)}=\sum_{j=1}^{22}w_jz_{ij}
},
\qquad
w_j\ge0,\quad\sum_jw_j=1.
\]

等权：

\[
w_j=\frac1{22}
\]

是必要基线。

考虑指标冗余时，可比较 CRITIC 权重：

\[
c_j=\sigma_j\sum_{\ell=1}^{22}(1-\rho_{j\ell}),
\qquad
w_j^{C}=\frac{c_j}{\sum_tc_t}.
\]

再与等权作收缩组合：

\[
w_j=(1-\xi)\frac1{22}+\xi w_j^C,
\qquad0\le\xi\le1.
\]

这叫 CRITIC 与等权的组合，不能称为“熵权法”。

CRITIC 衡量信息差异，不自动代表训练价值；因此权重选择应通过人工核验和敏感性分析说明。若没有独立质量标签，可用等权作主结果、CRITIC 作对照，避免把无监督权重误称为最优权重。

最终质量分 \(Q_i\) 在下一部分通过有限补偿模型得到。

**三、任务二：定义冲突、解释成因并构建最终质量模型**

**1. 冲突的对象是同一文本内部的指标分歧**

首先保留一个总体离散度：

\[
D_i=
\sqrt{
\sum_{j=1}^{22}w_j(z_{ij}-Q_i^{(0)})^2
}.
\]

它用于描述 22 项评分的分散程度，但不直接代表测量错误，也不代表质量差。

更直接的冲突定义是“一项明显高，另一项明显低”。

设：

\[
h>l,\qquad [x]_+=\max(x,0).
\]

定义有方向的冲突程度：

\[
c_{i,j\to k}
=
\frac{
[z_{ij}-h]_+[l-z_{ik}]_+
}{
(1-h)l
}.
\]

于是：

\[
0\le c_{i,j\to k}\le1.
\]

无方向冲突为：

\[
c_{i,jk}
=
\max(c_{i,j\to k},c_{i,k\to j}).
\]

可先设置 \(h=0.75,l=0.25\)，并检验其他阈值。它们是预设的评价阈值，不是统计学普遍定律。

样本冲突标签：

\[
I_i=
\mathbf1\{\exists j<k:c_{i,jk}>0\}.
\]

样本总体冲突强度：

\[
K_i^{\mathrm{diag}}
=
\sum_{j<k}\omega_{jk}c_{i,jk},
\qquad
\omega_{jk}\ge0,\quad\sum_{j<k}\omega_{jk}=1.
\]

主描述统计可对全部 231 对指标等权计算，再报告最严重的几类冲突。不能只保留负相关指标对，否则会漏掉总体正相关指标中的异常分歧。

这里的 \(K_i^{\mathrm{diag}}\) 用于**描述冲突**，不自动意味着所有这些差异都应扣分。

**2. 域内 MAD 用来识别“异常强的分歧”**

在 A1 中，对域 \(g\) 估计：

\[
m_g=\operatorname{median}(D_i:i\in g),
\]

\[
s_g=1.4826\operatorname{median}(|D_i-m_g|:i\in g).
\]

定义：

\[
R_i=\frac{D_i-m_g}{s_g}.
\]

当 MAD 为零或很小时，需要预设尺度下限，或改用其他稳健尺度，并记录处理方式。

\(R_i>3\) 可以标记“比本域常见文本分歧明显更强”的样本，但不能取代前面的高—低冲突定义：

- \(I_i\)：是否存在明显的高低分歧；
- \(D_i,K_i^{\mathrm{diag}}\)：分歧有多强；
- \(R_i\)：这种分歧在本域是否异常。

域内标准化可能使一个普遍分歧很强的域得到较低异常率，因此跨域比较应同时报告原始强度和域内异常率。

A2、A3 必须复用 A1 的 \(m_g,s_g\)，不能重新估计后仍声称使用了同一个阈值。

**3. 通过三类证据分析冲突成因**

第一类是指标关系。

计算全部样本和各域内部的 Spearman 相关矩阵，检查相关方向是否稳定；再控制来源域、文本长度等因素，计算残差相关或采用回归分析。

例如：

\[
\operatorname{rank}(z_j)
=f_j(g,\log(1+\text{length}))+e_j,
\]

\[
\rho_{jk}^{\mathrm{adj}}
=\operatorname{corr}(e_j,e_k).
\]

比较原始相关和调整后相关，可以判断关联是否主要由域构成或文本长度解释。相关系数仍不是因果证据。

第二类是潜在结构。

使用探索性因子分析：

\[
\boldsymbol z_i
=
\boldsymbol\Lambda\boldsymbol f_i+\boldsymbol\varepsilon_i.
\]

采用平行分析确定因子数，使用允许因子相关的斜交旋转，结合载荷解释潜在结构。可能出现内容价值、语言表达、文本污染或技术符号等因子，但名称必须由计算结果决定。

不因提取了若干因子而重新将质量评分强制分组；这里的因子仅服务于成因解释。

第三类是原文证据。

在 A1 中按来源域、质量水平和冲突类型分层抽取原文，区分：

| 原因 | 典型情况 | 处理 |
|---|---|---|
| 真实质量短板 | 教育内容中混入广告、重复或乱码 | 综合评价限制补偿 |
| 正常领域差异 | 代码符号多、论文公式多 | 修正指标适用规则 |
| 评分器误判 | 把代码字符串或参考文献误认作污染 | 核查并评估可靠性 |
| 预处理错误 | 广告方向反了、logits 被平均 | 修正后重算 |

不能预先宣布“学术严谨性与流畅度存在固有矛盾”。正确结论应是：在何种数据、控制哪些因素后，观察到什么关系，原文是否支持该解释。

**4. 有方向的冲突共现分析**

定义：

\[
M_{j\to k}
=
\sum_i
\mathbf1(z_{ij}\ge h,\ z_{ik}\le l).
\]

它表示“指标 \(j\) 高、指标 \(k\) 低”的次数。

除数量外，应报告比例和相对独立出现的提升程度：

\[
\operatorname{Lift}_{j\to k}
=
\frac{
P(z_j\ge h,z_k\le l)
}{
P(z_j\ge h)P(z_k\le l)
}.
\]

分母过小的指标对不作强解释。必要时控制多重比较，并用重抽样区间报告稳定性。

共现和 Lift 提供“哪些模式值得解释”的证据，原文核验才帮助判断这些模式的实际含义。

**5. 最终综合评价模型：有单调性保证的有限补偿**

经上述分析，从全部分歧中选出少量需要限制补偿的指标对，记为：

\[
\mathcal E.
\]

例如，经原文确认后，可以认为“教育价值”和“无广告”需要同时达到一定水平；而“专业性高、自然语言流畅度偏低”若主要反映代码或公式特征，则不应自动加入扣分集合。

选对的依据包括语义、统计模式和原文证据；不能简单令“负相关越强，扣分越重”。

定义最终评分：

\[
\boxed{
Q_i
=
\sum_{j=1}^{22}w_jz_{ij}
-
\sum_{(j,k)\in\mathcal E}
\theta_{jk}|z_{ij}-z_{ik}|
}
\]

并施加：

\[
\theta_{jk}\ge0,
\]

\[
\boxed{
\sum_{k:(j,k)\in\mathcal E}\theta_{jk}\le w_j
\quad\text{对每个 }j
}.
\]

这项约束是整个模型的关键。

利用：

\[
|z_j-z_k|=z_j+z_k-2\min(z_j,z_k),
\]

可把模型改写为：

\[
Q_i
=
\sum_jb_jz_{ij}
+
2\sum_{(j,k)\in\mathcal E}
\theta_{jk}\min(z_{ij},z_{ik}),
\]

其中：

\[
b_j=w_j-\sum_{k:(j,k)\in\mathcal E}\theta_{jk}\ge0,
\]

且：

\[
\sum_jb_j+2\sum_{(j,k)\in\mathcal E}\theta_{jk}=1.
\]

因此可以直接证明：

\[
0\le Q_i\le1,
\]

\[
Q_i(\boldsymbol0)=0,\qquad Q_i(\boldsymbol1)=1,
\]

并且每个已正向化指标提高，\(Q_i\) 都不会下降。

这一模型是二可加 Choquet 聚合的一种受限形式：保留单指标贡献，并引入需要“共同表现好”的成对项。Choquet 聚合及其指标交互解释有成熟的多准则评价理论依据。[Grabisch 与 Roubens 关于 Choquet 综合评价的论文](https://ikojadin.perso.univ-pau.fr/kappalab/pub/GraRouCOLL2000.pdf)

**模型如何消解冲突？**

假设仅有教育价值和无广告两项：

\[
w_1=w_2=0.5,\qquad\theta_{12}=0.25.
\]

对于：

\[
(0.9,0.1),
\]

基础平均为 \(0.5\)，最终：

\[
Q=0.5-0.25\times0.8=0.3.
\]

对于：

\[
(0.5,0.5),
\]

最终：

\[
Q=0.5.
\]

若把第一篇的无广告分数从 \(0.1\) 提高到 \(0.2\)：

\[
Q=0.55-0.25\times0.7=0.375,
\]

质量分随指标改善而上升。

这里同时保存：

\[
Q_i^{(0)},\qquad
K_i^{\mathrm{diag}},\qquad
P_i=\sum_{(j,k)\in\mathcal E}\theta_{jk}|z_{ij}-z_{ik}|,\qquad
Q_i.
\]

它们分别表示基础质量、诊断冲突、实际限制补偿的幅度和最终质量。诊断中发现的每一种差异，不必都进入惩罚。

**6. 参数怎样确定？**

有独立人工标注时，在校准集上估计少量 \(\theta_{jk}\)：

\[
\min_{\theta}
\sum_{i\in\mathcal H_{\mathrm{cal}}}
(H_i-Q_i(\theta))^2
+\lambda_\theta\sum_{(j,k)\in\mathcal E}\theta_{jk}^2,
\]

并保持前述非负和单调性约束。可固定基础权重 \(w_j\)，只估计少量交互参数，降低过拟合风险。

如果没有标注，可以采用透明的规则参数化。设 \(d_j\) 为指标 \(j\) 参与的配对数：

\[
\theta_{jk}
=
\eta
\min\left(\frac{w_j}{d_j},\frac{w_k}{d_k}\right),
\qquad0\le\eta\le1.
\]

该构造自动满足单调性约束。对若干 \(\eta\) 进行敏感性分析；它属于明确的评价偏好，不应宣称是数据识别出的最优参数。

Huber 可以作为综合评分对照，或用于人工评分回归中的稳健损失，但不承担“偏离多数的广告低分应被降权”的判断。

**7. 验证冲突消解是否有效**

不能用“扣分后冲突样本排名下降”证明有效，因为这是公式本身保证的。

推荐建立原文盲审集：

- 覆盖各来源域；
- 覆盖高、低基础质量；
- 覆盖高、低冲突；
- 评阅者不看模型分数；
- 同时标注整体质量、具体缺陷和是否属于正常领域特征。

校准集用于确定参数，独立评估集用于检验。若分层抽样比例与总体不同，报告总体指标时要按抽样概率加权。

比较以下模型：

| 模型 | 作用 |
|---|---|
| 等权平均 | 最基本基线 |
| 基础加权平均 \(Q^{(0)}\) | 检查权重作用 |
| Huber 综合评分 | 检查稳健中心思路 |
| 有限补偿评分 \(Q\) | 检查冲突处理的增益 |

评价指标包括：

\[
\operatorname{Spearman}(Q,H),
\]

人工质量等级对应的 MAE，以及固定选取比例下的“不合格文本占比”。

还应检查高价值论文、代码被错误降分的比例。若污染文本误选减少，却大量误伤代码，模型仍需修正。

人工评分是独立评价依据，不等于真实训练收益。Meta-rater 使用代理训练实验连接多维评分与验证 Loss；本题若未实施此类实验，就应把验证结论限定为“与独立文本质量判断更一致”。[Meta-rater，ACL 2025](https://aclanthology.org/2025.acl-long.533/)

**四、任务一、二的域级聚合与扩展集检验**

对域 \(g\) 的全部唯一文本计算：

\[
\boxed{
Q_g=\frac1{n_g}\sum_{i\in g}Q_i
}.
\]

均值作为主结果，因为低质量尾部也是待评价对象；中位数、截尾均值和分位数作为补充。

域级冲突输出：

\[
\bar K_g=\frac1{n_g}\sum_{i\in g}K_i^{\mathrm{diag}},
\]

\[
r_g=\frac1{n_g}\sum_{i\in g}I_i,
\]

\[
\bar P_g=\frac1{n_g}\sum_{i\in g}(Q_i^{(0)}-Q_i).
\]

最终结果表包括：

| 域 | 唯一文本数 | 基础质量 | 最终质量 | 质量分位数 | 冲突率 | 冲突强度 | 主要冲突类型 |
|---|---:|---:|---:|---|---:|---:|---|

对 arXiv、GitHub 分别输出：

\[
Q_g^{A1},\quad Q_g^{ext},\quad Q_g^{union},
\]

\[
\Delta Q_g=Q_g^{ext}-Q_g^{A1},
\]

以及冲突率差、主要冲突类型占比差、评分分布差异。

处理重叠时：

- 文件全量描述可以保留各自全部记录；
- 推断比较可使用 A1 与“扩展集中的非重叠部分”；
- 或在唯一文本层面重抽样，并保留文件成员关系。

不能把重叠部分当作独立样本。若来源文件具有明显聚类，应尽可能按来源块重抽样；无法处理抽样机制时，区间只能说明附件内的重抽样稳定性。

扩展验证需要冻结：

\[
\text{转换、尺度、权重、配对集合、阈值、交互参数}.
\]

至少检验：

1. 域级质量是否变化；
2. 冲突率和强度是否变化；
3. 主要冲突类型是否保持；
4. 评分修正是否主要作用于相同类型文本。

A2/A3 缺少原文时，它们能直接验证信号层面的结论；不能声称已独立验证所有语义成因。若 A1 是其子集，“扩展验证”主要是样本覆盖扩展，外部独立性也需说明。

**五、任务三：17 域配比与交叉熵损失的定量关系**

**1. 严格区分拟合、检验和外推**

| 数据配对 | 作用 | 配方数 |
|---|---|---:|
| A4＋A5 | 1M 主拟合 | 512 |
| A6＋A7 | 1M 同尺度检验 | 256 |
| A8＋A9 | 60M 跨尺度检验 | 256 |
| A10＋A11 | 1B 跨尺度检验 | 64 |
| A12＋A13 | 10B 外推讨论 | 63 |
| A14＋A15 | 70B 外推讨论 | 63 |

各组内部以 `index` 一对一连接；跨组相同 `index` 不自动代表相同配方，必须核对配比值。

定义：

\[
\boldsymbol p_i=(p_{i1},\ldots,p_{i17}),
\]

\[
p_{ia}\ge0,\qquad\sum_ap_{ia}=1,
\]

响应为：

\[
\boldsymbol L_i=(L_{i1},\ldots,L_{i13}).
\]

四个没有单独验证 Loss 的训练域仍需保留，研究它们对其他验证域的影响。

轻微舍入误差可归一化；明显负值或异常配比和必须先核查。

**2. 明确响应与汇总口径**

主模型预测每个验证域的原始交叉熵：

\[
\hat L_k=f_k(\boldsymbol p).
\]

为汇总 13 个验证域的预测表现，可预先规定固定权重：

\[
L_{\mathrm{agg}}(\boldsymbol p)
=
\sum_{k=1}^{13}v_kL_k(\boldsymbol p),
\qquad
v_k\ge0,\quad\sum_kv_k=1.
\]

没有额外任务偏好时，可用等权宏平均：

\[
v_k=\frac1{13}.
\]

这是验证域宏平均 Loss，不自动等于整个验证语料按 Token 加权的 Loss。

**3. 用混合响应模型处理单纯形约束**

配比中的零通常表示某领域未被使用。解释领域和组合效应时，可采用无需对零取对数的二次混合模型：

\[
\boxed{
L_{ik}
=
\sum_{a=1}^{17}b_{ak}p_{ia}
+
\sum_{a<b}\gamma_{ab,k}p_{ia}p_{ib}
+
\varepsilon_{ik}
}.
\]

它共有：

\[
17+\binom{17}{2}=153
\]

个候选特征。

不额外加入自由截距，因为：

\[
1=\sum_ap_a.
\]

也不再放入全部平方项，因为：

\[
p_a^2=p_a-\sum_{b\ne a}p_ap_b.
\]

这一表示既适应单纯形，也能直接处理零配比。

实际数据仍可能缺少某些领域组合，应检查设计矩阵秩、领域出现频率和组合覆盖率；没有观测支持的交互参数不能强解释。

**4. 模型估计与选择**

用正则化控制 153 个特征的复杂度：

\[
\min_{B,\Gamma}
\frac1n\|Y-\Phi(B,\Gamma)\|_F^2
+\lambda_B\|B\|_F^2
+\lambda_\Gamma\|\Gamma\|_F^2.
\]

对交互项施加更强约束，避免把噪声解释为互补效应。

至少比较：

- 一次混合模型；
- 正则化二次混合模型；
- 一个经过交叉验证调参的非线性预测模型。

仅在 A4+A5 内选择模型和参数。重复、近重复配方按组划分交叉验证，所有标准化步骤在训练折内部完成。

RegMix 的研究路线就是利用小模型的不同配方实验，学习配比—性能关系，再考察大模型迁移；它提供了本题回归建模的直接背景。[RegMix 官方研究仓库](https://github.com/sail-sg/regmix)

**5. 分析领域作用：使用可行配比替换**

提高某领域比例必须挤占其他领域，不能解释成“其他比例不变时增加某域”。

定义从领域 \(b\) 向领域 \(a\) 转移 \(\delta\)：

\[
\boldsymbol p'
=
\boldsymbol p+\delta(\boldsymbol e_a-\boldsymbol e_b),
\qquad0\le\delta\le p_b.
\]

效应为：

\[
\boxed{
\Delta_{a\leftarrow b,k}
=
\hat L_k(\boldsymbol p')-\hat L_k(\boldsymbol p)
}.
\]

负值表示该替换降低 Loss，正值表示提高 Loss。

局部导数为：

\[
ME_{a\leftarrow b,k}
=
\frac{\partial\hat L_k}{\partial p_a}
-
\frac{\partial\hat L_k}{\partial p_b}.
\]

二次模型中：

\[
\frac{\partial\hat L_k}{\partial p_a}
=
b_{ak}+\sum_{\ell\ne a}\gamma_{a\ell,k}p_\ell.
\]

因此领域贡献依赖基准配方。建议在观测配方附近计算，再对可行样本平均，输出替换效应矩阵及稳定性区间。

这些是实验条件下的模型效应；数据和训练设置不能支持的普遍因果结论不应外推。

**6. 分析组合效应**

对两个受数据支持的配方：

\[
\boldsymbol p(t)
=
t\boldsymbol p^{A}+(1-t)\boldsymbol p^{B},
\]

定义：

\[
H_k(t)
=
\hat L_k(\boldsymbol p(t))
-
[t\hat L_k(\boldsymbol p^{A})+(1-t)\hat L_k(\boldsymbol p^{B})].
\]

若 \(H_k(t)<0\)，混合优于两端 Loss 的线性插值，支持该路径上的协同；若 \(H_k(t)>0\)，表明不利交互。

要归因于特定领域组合，应设计只改变相关领域的可行路径，并说明剩余配比如何调整。不能只看某个回归系数的符号，就宣布某两个领域普遍互补。

Bootstrap 时重抽整个配方实验，保留同一配方的 13 项 Loss。若要报告模型选择后的不确定性，应把选择过程也纳入重抽样，或明确区间以已选模型为条件。

**7. 是否引入 \(Q\)：作为配比预测的质量先验检验**

先用 A16 建立 17 个训练域与 A1–A3 质量域的**候选映射**。其中仅 3 个直接映射、3 个近似映射，另外 11 个没有对应的质量域。因此下式只在映射有依据的域上给出质量代理，不能将 17 个域都视为已经测得质量：

\[
\tilde Q_a=\sum_gM_{ag}Q_g,
\qquad
M_{ag}\ge0,\quad\sum_gM_{ag}=1.
\]

对已映射的配方质量贡献及覆盖份额分别定义：

\[
C(\boldsymbol p)=\sum_{a\in\mathcal M}p_a\tilde Q_a,
\qquad m(\boldsymbol p)=\sum_{a\in\mathcal M}p_a.
\]

\(C\) 不是完整的配方质量。若假设未知域的质量分处于 \([0,1]\)，完整配方质量只能给出宽泛界 \([C,C+1-m]\)；用已映射域均分补齐未知域只能作为标注清楚的情景分析。A2/A3 可对 arXiv/GitHub 的 A1 映射分做尺度冻结后的敏感性对照。

A17 提供每个 RegMix 域的样本量、长度和来源路径，A18 提供相应原始文本。应全量流式检查 17 域覆盖、A17/A18 行数和路径一致性、空文本及明显损坏或重复等结构问题。这些证据能审计映射的适用性，却**不是**与 A1–A3 同口径的 22 指标质量评分：A18 没有预计算质量信号，而且来自 `valid/` 分片。若要用 A18 估计新的 RegMix 域级 \(Q\)，必须对原文另行应用经过校准的统一评分器、评估样本代表性与领域适用性，并报告估计误差；不可把字符长度或样本数直接当 \(Q\)。

即使未来得到 17 个固定域级 \(\tilde Q_a\)，配方质量仍是已有配比变量的确定性线性组合：

\[
\sum_ab_ap_a+\beta Q_{\mathrm{mix}}
=
\sum_a(b_a+\beta\tilde Q_a)p_a.
\]

因此 A4—A15 不能单独识别“领域配比效应”和“固定域质量效应”；A17/A18 的文本描述也不提供固定配比下改变质量的受控 Loss 实验。

质量路线的原则：

- 先建立不含质量的 \(L=f(\boldsymbol p)\) 基线；
- 对 A16 未映射的十一域，通过 A1/A18 共同信号画像估计软映射，或由 A18 重建信号复用任务 1/2 冻结评分器直接估计域级 \(Q\)；保守边界和情景分析保留为无可靠桥接时的参照；
- direct、near_direct、inferred 映射分层报告；
- 把 A17/A18 的来源、覆盖和文本完整性审计与跨库质量映射分开报告；
- 映射不确定性和 A1–A3 域质量估计的不确定性应在论文推断中传播；
- 不把不同语料来源间的域映射当作精确实验对应。

固定域级 \(Q\) 与配比构成确定性关系，不能据此识别独立质量效应。是否采用质量增强的预测模型，应先检查共同信号复现、A16 锚点和 A1 留一域质量迁移，再在 A4+A5 内选模，并以 A6–A11 的 Loss 预测检验和 A12–A15 外推诊断论证；不能仅因加入 \(Q\) 就声称模型改善。

**2026-09-25 实验结果补充。**A1 原文上已有 9 项统计信号和 5 项公开模型信号通过总体复现审计，A18 已产生同口径重建矩阵。[任务 3 实验结果](报告/任务3_实验结果.md)以 A16 六条固定映射为锚，对其余十一域作 A1/A18 画像软映射；另一条路线把 A18 重建信号送入任务 1/2 冻结评分器直接估计 \(Q\)。两条路线通过各自的跨域质量门禁。A4+A5 五折选中的 M3-direct 在 A6–A11 三个真实检验集的 13 输出 RMSE 均低于本轮候选模型，故作为当前**主预测模型**；不含 \(Q\) 的 M1-RBF 为基线，二次混合模型和可行替换用于领域/组合解释。A12–A15 估算外推表上 M3-direct 未保持优势。质量迁移门禁样本有限，且 A18 `valid/` 不等于真实训练语料，因此只可称为有条件的预测增益，不能称独立质量因果效应。

**六、在 A6—A11 上验证，在 A12—A15 上讨论外推**

**1. 同尺度验证**

A6+A7、A8+A9、A10+A11 分尺度逐验证域报告：

\[
MAE_k=\frac1n\sum_i|L_{ik}-\hat L_{ik}|,
\]

\[
RMSE_k=
\sqrt{\frac1n\sum_i(L_{ik}-\hat L_{ik})^2},
\]

以及 \(R^2\)、Spearman 相关和残差图。RMSE、MAE 衡量 Loss 预测误差；Spearman 辅助检查不同配比的相对性能关系。13 个验证域分别检查，避免汇总指标掩盖个别域失效。

**2. 跨尺度验证**

在 A8+A9 和 A10+A11 上，报告不使用目标尺度标签的直接迁移预测误差、\(R^2\) 与分验证域相关，并检查训练集上识别的配比替换方向是否稳定。

单纯的 1M 配比模型没有识别尺度变化的足够信息，绝对 Loss 预测可能存在系统偏差。若报告直接迁移 RMSE，应如实保留该偏差，不能用测试集均值事后修正。

如需校准：

\[
L_{ik}^{(s)}
=
a_{sk}+b_{sk}\hat L_k^{(1M)}(\boldsymbol p_i)+e_{ik},
\]

需用独立校准子集或交叉拟合；剩余样本评价。校准结果与无标签迁移结果分开报告。

**3. 外推稳健性**

A12+A13、A14+A15 成对使用，检查外推估计 Loss 的误差与相关、领域替换/组合结论是否稳定、不同模型及扰动下趋势是否一致，以及外推表是否近似由小尺度 Loss 的固定缩放或简单变换生成。

若外推表只是训练结果的统一变换，一致性不能作为真实大模型有效性的独立证据。

外推表不参与主模型拟合，也不作为新增真实观测扩大显著性。最终结论明确区分：

\[
\text{真实检验数据支持}
\quad\text{和}\quad
\text{给定外推规则下的一致性}.
\]

> 本文在统一尺度下融合官方质量指标，将质量水平、指标分歧与测量可靠性分别处理。通过高低评分共现、调整后相关、因子结构和原文核验分析冲突来源，并构建具有边界性和单调性保证的有限补偿评价函数。随后在单纯形上建立领域配比与多验证域交叉熵的定量关系，以可行配比替换与二次混合模型分析领域及组合效应；在 A6–A11 检验 Loss 预测，在 A12–A15 估算外推表讨论趋势稳定性，并以十四项跨库信号检验质量先验能否改善预测。

而“哪个域最好、冲突消解提升多少、哪些组合有效”等实质性结论，应在上述计算和独立验证完成后填写。
