\section{问题二：跨维度数据融合与广义标度律模型设计}

\subsection{问题分析}

问题一主要研究了训练数据自身属性，包括数据质量评价以及不同领域数据比例对模型性能的影响。
然而，经典大语言模型标度律（Scaling Law）通常只考虑模型规模和数据规模两个因素：

\[
L(N,D)=L_0+A N^{-\alpha}+B D^{-\beta}
\]

其中，$N$表示模型参数规模，$D$表示训练数据量，$L$表示验证集交叉熵损失。

该模型能够描述模型规模扩大带来的性能提升规律，但存在两个不足：

\begin{enumerate}
    \item 未考虑训练数据质量差异。
    不同来源的数据虽然具有相同Token数量，但由于噪声、重复、知识密度等因素不同，其有效贡献并不相同。

    \item 未考虑数据领域组成差异。
    不同领域数据对模型能力提升的贡献不同，同时多个领域之间可能存在互补关系。
\end{enumerate}

因此，问题二的目标是在经典Scaling Law基础上，引入问题一得到的数据质量评价结果$Q$以及领域配比$p$，建立更加完整的广义标度律：

\[
L=f(N,D,Q,p)
\]

并进一步分析不同资源投入方式之间的等价关系。


\subsection{模型设计总体思路}

模型设计过程分为三个步骤：

\begin{enumerate}
    \item 保留经典Scaling Law中参数规模$N$和数据规模$D$的影响；
    \item 将数据质量$Q$转化为有效数据量，使质量因素能够统一进入Scaling Law；
    \item 将领域配比$p$建模为领域组合收益函数，描述不同数据混合方式带来的额外收益。
\end{enumerate}


最终希望构造：

\[
Loss=
f(N,D_{\mathrm{eff}})
\]

其中：

\[
D_{\mathrm{eff}}
=
D\times Quality\ Gain\times Domain\ Gain
\]


即：

\[
D_{\mathrm{eff}}
=
D\times Q^\gamma\times M(p)
\]


其中：

\begin{itemize}
    \item $Q$：数据质量评分，由问题一得到；
    \item $\gamma$：质量影响强度参数；
    \item $M(p)$：领域混合收益函数。
\end{itemize}



\section{候选方案分析}

\subsection{方案一：纯神经网络模型}

一种直接方法是将所有因素输入神经网络：

\[
L=f_\theta(N,D,Q,p)
\]

例如：

\[
L=MLP(N,D,Q,p)
\]


\subsubsection{优点}

\begin{itemize}
    \item 能够拟合复杂非线性关系；
    \item 不需要人工设计函数形式；
    \item 对预测任务可能具有较高精度。
\end{itemize}


\subsubsection{缺点}

但是，该方法存在明显不足：

\begin{itemize}
    \item 模型缺乏可解释性；
    \item 难以推导$\frac{\partial L}{\partial Q}$等弹性指标；
    \item 难以回答题目要求的：
    
    ``提升数据质量0.1相当于增加多少参数规模''。
\end{itemize}


因此，纯神经网络不适合作为问题二的主体模型。


\subsection{方案二：纯数学Scaling Law模型}

保持可解释性，直接扩展经典形式：

\[
L=
L_0+
A N^{-\alpha}
+
B D^{-\beta}
+
C Q^{-\eta}
\]


\subsubsection{优点}

\begin{itemize}
    \item 形式简单；
    \item 参数具有明确数学意义；
    \item 易于进行弹性分析。
\end{itemize}


\subsubsection{不足}

该方法假设：

\[
D,Q
\]

相互独立。

但是实际中：

\[
高质量数据
\neq
额外增加数据量
\]

质量本质上改变的是数据有效利用程度。


因此，单独增加$Q$项无法很好体现数据质量和数据规模之间的关系。


\subsection{方案三：有效数据量模型（推荐）}

参考大模型数据质量研究中的思想，将质量转化为有效数据规模：

\[
D_{\mathrm{eff}}
=
D Q^\gamma
\]


其中：

\begin{itemize}
    \item $D$表示真实Token数量；
    \item $Q^\gamma$表示质量带来的有效利用比例；
    \item $\gamma$表示质量敏感程度。
\end{itemize}


于是：

\[
L=
L_0+
A N^{-\alpha}
+
B(DQ^\gamma)^{-\beta}
\]


该模型具有以下特点：

\begin{enumerate}
    \item 当$Q=1$时：

    \[
    D_{\mathrm{eff}}=D
    \]

    自动退化为经典Scaling Law。

    \item 可以直接比较：
    
    增加数据量和提升数据质量的效果。

    \item 参数具有明确解释。
\end{enumerate}



\section{领域配比建模设计}

问题一已经分析：

\[
p=(p_1,p_2,...,p_k)
\]

表示不同领域数据比例。


需要进一步考虑：

不同领域之间不仅具有独立贡献，还可能存在协同关系。


例如：

\[
数学+代码
\]

可能比简单相加效果更好。


因此设计领域收益函数：


\[
M(p)
=
\sum_{i=1}^{k}a_ip_i
+
\sum_{i<j}b_{ij}p_ip_j
\]


其中：


第一部分：

\[
\sum_i a_ip_i
\]


表示单个领域贡献。


第二部分：

\[
\sum_{i<j}b_{ij}p_ip_j
\]


表示领域之间互补关系。


最终：

\[
D_{\mathrm{eff}}
=
D Q^\gamma M(p)
\]


\section{最终推荐广义标度律模型}


综合以上分析，最终采用：

\[
\boxed{
L=
L_0+
A N^{-\alpha}
+
B
(DQ^\gamma M(p))^{-\beta}
}
\]


其中：


\[
M(p)
=
\sum_i a_ip_i
+
\sum_{i<j}b_{ij}p_ip_j
\]


因此完整模型为：


\[
\boxed{
L=
L_0+
A N^{-\alpha}
+
B
\left(
D Q^\gamma
(
\sum_i a_ip_i+
\sum_{i<j}b_{ij}p_ip_j
)
\right)^{-\beta}
}
\]


\section{模型参数估计方案}


模型参数：

\[
\Theta=
\{
L_0,A,B,\alpha,\beta,\gamma,a_i,b_{ij}
\}
\]


采用分阶段估计。


\subsection{阶段一：经典Scaling Law拟合}


利用B1数据：

\[
(N,D,L)
\]


拟合：

\[
L=
L_0+A N^{-\alpha}+BD^{-\beta}
\]


得到：

\[
L_0,A,B,\alpha,\beta
\]


\subsection{阶段二：加入质量因素}


利用B6-B8数据：

\[
(N,D,Q,L)
\]


进一步估计：

\[
\gamma
\]


得到：

\[
D_{\mathrm{eff}}=DQ^\gamma
\]


\subsection{阶段三：加入领域配比}


利用问题一输出：

\[
Q,p
\]


构造：

\[
M(p)
\]


并估计：

\[
a_i,b_{ij}
\]


最终得到完整模型。


\section{模型验证方案}


\subsection{预测精度验证}

采用：

\[
RMSE
\]

和：

\[
MAE
\]


评价预测误差。


\subsection{跨数据验证}


验证数据：

\begin{itemize}
    \item B2：Cerebras训练轨迹；
    \item B3：Pythia插值轨迹；
    \item B4：跨模型族数据；
    \item B5：已有文献Scaling数据。
\end{itemize}


\subsection{质量因素有效性验证}


比较：

\[
L(N,D)
\]

与：

\[
L(N,D,Q)
\]


预测效果差异。


如果加入$Q$后：

\[
RMSE下降
\]

说明数据质量确实影响Scaling规律。


\section{进一步分析：资源等价关系}


根据模型计算弹性：


参数规模弹性：

\[
E_N=
-\frac{\partial L}{\partial N}
\frac{N}{L}
\]


质量弹性：

\[
E_Q=
-\frac{\partial L}{\partial Q}
\frac{Q}{L}
\]


比较：

\[
E_N,E_Q
\]


即可判断：

\begin{itemize}
    \item 增加参数是否更有效；
    \item 提升数据质量是否更有效。
\end{itemize}


进一步令：

\[
dL=0
\]


可推导：

\[
\Delta N
\leftrightarrow
\Delta Q
\]


即：

\[
\boxed{
\text{质量提升多少}
\approx
\text{参数增加多少}
}
\]


\section{最终方案总结}

最终采用：

\[
\boxed{
\text{可解释数学Scaling Law}
+
\text{有效数据量}
+
\text{领域协同函数}
}
\]


而不是直接使用神经网络。


原因：

\begin{enumerate}
    \item 符合Scaling Law研究范式；
    \item 满足数学建模可解释要求；
    \item 可以进一步进行弹性分析；
    \item 可以自然连接问题三的算力优化。
\end{enumerate}
